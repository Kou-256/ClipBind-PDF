ご利用方法How it works

  1. 画像をコピーするCopy images

    Win+Shift+S のスクリーンショットや、ブラウザの「画像をコピー」など。いつものやり方で大丈夫です。Screenshots with Win+Shift+S, "Copy image" in a browser — however you usually copy.

  2. 履歴からまとめて取り込むImport the history

    ［クリップボード履歴から取り込み］を押すと、Win+V に残っている画像がコピーした順に並びます。アプリを開いたままなら、コピーするたびに自動で追加されます。Press [Import clipboard history] and the images still in Win+V line up in the order you copied them. With the app open, each new copy is added automatically.

  3. 並べ替えるArrange

    ドラッグで順番を入れ替え、回転・削除もその場で。消しても［元に戻す］で取り消せます。Drag to reorder, rotate or remove. Removed something by mistake? Undo brings it back.

  4. PDF を作成Create the PDF

    ボタンひとつで保存。保存先は最初はダウンロード フォルダーです。One button saves it — to your Downloads folder unless you choose another.

ご注意Good to know

  • 画像はパソコンの外に出ませんYour images never leave your PC

    すべてお使いのパソコンの中で処理します。どこにもアップロードしません。Everything happens on your computer. Nothing is uploaded anywhere.

  • クリップボード履歴をオンにTurn on clipboard history

    取り込みには Windows の［設定］→［システム］→［クリップボード］→［クリップボードの履歴］がオンになっている必要があります。オフのときはアプリが設定画面を案内します。Importing needs Settings → System → Clipboard → Clipboard history turned on. If it's off, the app takes you to the setting.

  • 「Windows によって PC が保護されました」と出たらIf you see "Windows protected your PC"

    インストーラーにコード署名をしていないため表示されることがあります。［詳細情報］→［実行］で進めてください。The installer isn't code-signed yet, so SmartScreen may warn. Choose More info → Run anyway.

  • 動作環境Requirements

    Windows 10 (1809 以降) / Windows 11、64 ビット。.NET の追加インストールは不要です。Windows 10 (1809 or later) or Windows 11, 64-bit. No separate .NET install needed.
